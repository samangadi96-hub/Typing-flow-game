# Typing Flow Game

A Python-based typing game developed as a first semester group project.

## Overview
Typing Flow Game is designed to test and improve a user's typing accuracy and speed. 
The game calculates real-time Words Per Minute (WPM) and evaluates typing accuracy 
while offering multiple levels of difficulty.

## Features
- Real-time Words Per Minute (WPM) calculation
- Typing accuracy evaluation
- Multiple difficulty levels
- Interactive command-line interface

## Technologies Used
- Python
- Pygame library

## How to Run
1. Make sure Python and pygame library is installed.
2. Download or clone this repository.
3. Run the file using the command "python typing-flow-game.py" in your terminal.


## Learning Outcomes
- Implemented real-time input tracking
- Applied logic for speed and accuracy calculation
- Designed difficulty level handling
- Improved understanding of Python fundamentals
